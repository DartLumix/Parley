Parley — Linux desktop client
=============================

Install (no root, installs to ~/.local):

    ./install.sh

Then launch "Parley" from your app launcher, or run:

    ~/.local/bin/parley

Connect to a server:

    host or IP, port optional — the default QUIC port is 4443.
    With the release container mapped to host port 443, type
    "your-server:443".

Your login is a username and password created by the server owner:

    docker compose exec parley /parley-server adduser alice 'a password'

Closing the window does NOT sign you out: the app remembers the
server-issued session token (never your password) in
~/.config/parley/session.toml and reconnects to the last server on the
next launch. Use the Disconnect button in the app bar to sign out — that
deletes the token.

Click a name in a channel to set that person's volume; a screen sharer
has a second bar for their share's system audio. A muted mic shows a
muted-mic badge, and a name lights up while that person is speaking.

The first time you connect, the client pins the server's certificate
(the same TOFU model as SSH). Compare the fingerprint the server prints
on startup with the one the app shows after login.

If the owner ever regenerates the identity, the next login is refused:
the app shows the saved fingerprint beside the new one and offers to
trust it. Only accept after the new value matches the server's startup
log. (Settings are in ~/.config/parley/known_hosts if you need to look.)

Requirements: GTK 3, PipeWire (screen capture), ALSA (audio) and a
Wayland or X11 session. install.sh reports anything missing.

Screen sharing asks the desktop's portal for a capture stream. On
Hyprland install xdg-desktop-portal-hyprland; on GNOME, KDE and sway
use the matching backend. Audio and chat never need the portal.

Uninstall:

    ./install.sh --uninstall
